Quickstart in 10 Seconds

        
Install MonoFlow into any existing repository (Go, Node/TypeScript, Rust, Python, or polyglot monorepo):


        

          

            TERMINAL
            
          

          
# 1-line installation
curl -fsSL https://get.monoflow.dev/install.sh | bash

# Or build from source:
git clone https://github.com/M0xoo/monoflow.git
cd monoflow && make build && ./install.sh

Core Systems Architecture


        
1. The Sub-2s Inner Loop & Normalized JSON Diagnostics

        
Agents should never spend reasoning tokens parsing ANSI terminal escapes. MonoFlow executes affected targets in parallel goroutines and normalizes diagnostics across TypeScript (tsc/biome), Go (vet/build/test), Rust (cargo), and Python (ruff/pytest) into structured JSON:


        

          

            JSON COMPILER DIAGNOSTIC
            
          

          
{
  "status": "failed",
  "duration_ms": 137.13,
  "affected_packages": ["services/billing-service"],
  "results": [
    {
      "target": "services/billing-service",
      "language": "go",
      "status": "failed",
      "errors": [
        {
          "file": "internal/billing/billing.go",
          "line": 5,
          "col": 1,
          "code": "go-error",
          "message": "syntax error: unexpected }, expected expression"
        }
      ],
      "command_run": "go build ./..."
    }
  ]
}

        


        
2. Ephemeral Checkpoints (Plumbing-Level Shadow Workspace)

        
Captures the entire working tree state in 15ms using low-level Git plumbing (git write-tree). When a trial edit fails, monoflow checkpoint revert restores the green workspace in 14ms without touching public Git commits.


        
3. Machine-Checked DoD & Proof of Work (PoW)

        
Before opening a PR, the agent executes monoflow task prove <task-id> to verify boundary scopes, compile hermetic staging into .agents/dist, and sign the Proof Receipt. Reviewers verify the PR in under 1 second:


        

          

            REVIEWER VERIFICATION
            
          

          
monoflow verify --proof=task-billing-discount
# Output verified in 0.159 milliseconds:
{
  "status": "VERIFIED",
  "task_id": "task-billing-discount",
  "verified_in_ms": 0.159,
  "dod_checks_passed": 4,
  "confidence_verdict": "APPROVED (1-Second Instant Verification Passed)"
}

        

      


      
      

        
Multi-Agent Swarms & Virtual Worktrees


        
1. Virtual Worktrees (< 60ms) & Copy-on-Write Dependencies

        
Autonomous agents operate in isolated Git worktrees under .agents/worktrees/<agent-id>. Dependencies (node_modules, .venv, target) are shared via instant symlinks (< 60ms). When an agent modifies dependencies, monoflow worktree isolate clones 2GB of dependencies in ~68ms at 0 bytes disk cost using APFS clonefile on macOS and Linux reflink.


        
2. Semantic Symbol-Level AST Synthesizer

        
When multiple agents edit the same file in different worktrees, standard Git triggers text conflict markers. MonoFlow parses native ASTs (Go ast, TypeScript, Python) to reconcile disjoint additions:


        

          
Zero Conflict Markers

          
If Agent Alpha adds func LogAuthEvent() and Agent Beta adds func LogBillingEvent() to the same file, MonoFlow synthesizes both declarations and deduplicates imports in 25.7ms.

        


        

          

            AST SYNC COMMAND
            
          

          
monoflow worktree sync --to=agent-alpha --from=agent-beta
# Result: packages/shared-go/logger/logger.go (synthesized AST) in 25.7ms

        


        
3. Heartbeat Leases & Automatic Garbage Collection

        
Orphaned worktrees from crashed or terminated agents lock Git branches. MonoFlow updates heartbeat leases on every run. monoflow worktree gc automatically sweeps worktrees older than their TTL and unlocks Git state.

      


      
      

        
Review Safeguards & CI Guardrails


        
1. Semantic Risk Scoring (0–100)

        
Quantifies PR blast radius based on database migrations (+35), security/auth (+30), infrastructure workflows (+25), test deficits (+20), and DAG transitive fan-out (+5 per dependent package):

        
    
          
  • TIER_1_AUTO_APPROVABLE (Score ≤ 20): Eligible for automated merge train (docs/tests only).
    • 
          
  • TIER_2_HUMAN_REVIEW_REQUIRED (Score 21–65): Business logic modified; standard review required.
    • 
          
  • TIER_3_ELEVATED_RISK_BLOCKED (Score > 65): Touches critical schemas, auth, or high churn.
    • 
        


        
2. PR Intent & Scope Auditor

        
Stops deceptive agent PRs where an agent claims "docs: minor typo fix" while secretly modifying SQL migrations or auth tokens:


        

          

            INTENT AUDIT COMMAND
            
          

          
monoflow review audit --title="docs: update readme" --desc="minor doc fixes"
# Result: Exit code 1 (Blocked)
# Undisclosed critical blast radius: 003_stripe_customer.sql modified in Git but omitted from PR description!

        


        
3. Speculative Local Merge Queue & Two-Tier CI

        
Pushing every agent micro-commit to GitHub Actions causes CI gridlock and inflates runner costs:

        
    
          
  1. monoflow queue spec <task-id> simulates landing on main locally in 36ms, testing only affected targets and bypassing quarantined flaky tests.
    2. 
          
  2. Issues a signed cryptographic pre-flight receipt.
    3. 
          
  3. In GitHub Actions, monoflow ci check validates the signature and activates Tier 1 Fast-Path (< 30s) instead of a 30-minute full build, slashing CI bills by up to 90%.
    4. 
        

      


      
      

        
Integrity Guardrails & Circuit Breakers


        
1. Anti-Cheating Test Integrity Guard

        
Agents frequently attempt to make CI green by deleting failing assertions, commenting out tests, or inserting hollow assertions like expect(true).toBe(true). MonoFlow inspects diffs and rejects any commit where assertions were weakened or mocked away.


        
2. Runaway Self-Correction Circuit Breaker

        
Caps inner-loop self-correction attempts at 3 iterations. If attempt 3 fails, MonoFlow auto-reverts the workspace to the latest green checkpoint and emits a structured Human Escalation payload, stopping runaway token spend.


        
3. Fast Agent Commit (monoflow commit)

        
Standard human pre-commit hooks (Husky, lint-staged, prettier) hang agents waiting for interactive stdin or take 40s per micro-commit. monoflow commit -m "..." validates test integrity and secret scanning in < 50ms, then commits with --no-verify.
