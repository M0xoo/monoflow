Core Engineering Subsystems

Architected for Parallel Swarms

Every component is built in native Go, compiling to a single static binary with zero runtime dependencies.

01 / DAG GRAPH

Sub-2s Inner Loop

Builds an in-memory directed acyclic graph across all workspace packages. Computes exact reverse-dependency sets so agents only compile and test packages directly affected by their changes.

In-Memory DAG Parallel Worker Pool < 2s Feedback
02 / GIT PLUMBING

15ms Snapshots

Bypasses human-facing Git porcelain commands (stash, commit). Directly invokes low-level git write-tree on shadow indexes, creating atomic commits without polluting the developer index.

git write-tree Zero Staging Churn Shadow Tree Shas
03 / ISOLATION

CoW Virtual Worktrees

Leverages host APFS (Darwin) and btrfs (Linux) clonefile() primitives to provision isolated agent worktrees in 58ms. Dependencies like node_modules and .venv share physical storage at 0 KB disk cost.

APFS clonefile Shared .venv Shared node_modules
04 / ZERO LOCKS

Same-File AST Synthesizer

Multiple agents can concurrently modify the exact same source file. Instead of crude line-based git conflicts, MonoFlow parses Go ASTs and synthesizes non-overlapping struct fields, imports, and methods in < 25ms.

Go AST Parser Semantic 3-Way Merge Lock-Free Swarms
05 / INTEGRITY

Slop & Scope Auditor

Detects prompt-injected hallucinated edits, unprompted file churn, and unauthorized test assertion deletions. Enforces strict task contract boundaries before any code hits the speculative queue.

Intent Classifier Anti-Cheating Guard Quarantine Sandbox
06 / VERIFICATION

Speculative Merge & PoW

Disjoint PRs are merged speculatively ahead of cloud CI. Generates machine-signed proof-of-work receipts (.monoflow/proofs/receipt.json) that human reviewers and CI gates verify in 0.159ms.

Topological Rebase SHA-256 Tree Sig Two-Tier Gate

Command Line Interface

CLI Command Reference

MonoFlow ships as a single statically linked binary with zero dependencies.

Command Description Flag Highlights
monoflow init Auto-discovers workspace topology and packages --json, --config <path>
monoflow run <task> Executes tasks only on affected DAG dependencies --scope affected|all, --parallel <n>
monoflow checkpoint Creates a 15ms shadow snapshot via git write-tree --message <msg>, --tag <name>
monoflow worktree spawn Provisions CoW worktree with shared virtual caches --agent <id>, --share-caches
monoflow synthesize <file> Synthesizes parallel AST modifications across agent branches --base <ref>, --branches <b1,b2>
monoflow audit --pr <id> Audits agent PR for intent adherence and prompt slop --strict, --quarantine-hallucinations
monoflow push <remote> <branch> Fire-and-forget push with background autonomous CI watcher --no-watch, --branch <b>
monoflow events unread Asynchronous agent event inbox (check in < 5ms without polling) --ack <id>, --clear
monoflow queue merge Enqueues PR into speculative DAG merge queue --speculative, --auto-rebase
monoflow receipt sign Emits machine-signed 1-second reviewer proof receipt --pr <id>, --output receipt.json
